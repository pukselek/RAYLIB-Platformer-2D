# [🎮] RAYLIB Platformer 2D

> Simple project made by me in C# language and created helper without library Raylib-gui
---

## [⚡] Functions in the Project
* **Sprite Animation System** - System making Player more realistic and added helper ('FlipH') to bounce image
* **Button Builder** - Easy helper for button without libraries, helper have ('Draw') function and ('OnButtonClick')
* **Constructor** Constructor is made to make program easiest to use and for new levels 
* **Pause Menu Builder** Pausing gameplay with ('ESC') Input
* **Player Build** Player builder is created to put player in any level, Builder have putted Gravity and Movement

## [🧩] Classes
* **Program** - Main Setup for Menu Class
* **Menu** - Selecting options like Play, About and Exit
* **FirstLevel** - Test Level for gameplay

## [🛠️] Technology used in Project
* **Programming Language** - C# (.NET 10.0)
* **Library** - [Raylib](https://www.raylib.com/) with [Raylib-cs](https://github.com/raylib-cs/raylib-cs)

## [🚀] How to launch this Project?
> Download **.NET SDK (v10.0) or newer version**
> Important C# environment
> If you have C# environment and .NET SDK v10.0, clone repository
> 
> ```bash
> git clone https://github.com/pukselek/RAYLIB-Platformer-2D.git
> ```
> 
> Select src folder by
> 
> ```bash
> cd ./RAYLIB-Platformer-2D/src
> ```
> 
> Active Program by
> 
> ```bash
> dotnet run
> ```
